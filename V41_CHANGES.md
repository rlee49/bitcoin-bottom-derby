# v41 final-polish test release

v41 continues from the accepted v40 coherent-motion test build. The locked v32 master remains unchanged.

## Racer refinements

- Rodster's cycle no longer displays the structural outlier pose that made the horse glitch during playback.
- Tom's earlier corn-humanoid rider and animated donkey identity are restored.
- Tatiana now uses black and gray instead of black and pink, while retaining her black flowing hair and coherent gallop geometry.
- Paddock avatars for Tom, Tatiana, and Rodster now match their revised track artwork. Supplied Discord portraits remain on the left lane cards.

## Contest and interface

- Prize changed from $100 in XRP to **$100 in TAO** in the live interface and rules template.
- Paddock Picks now uses a dark blue/black presentation with layered cards, supporter rows, colored racer headers, and stronger contrast.
- The locked-pick status box now shows only `YOUR PICK` and the selected racer name; the redundant `Paddock Picks` line is removed.
- Tatiana's UI accent is gray rather than pink.

## QA

- All 60 animation files are independent 600×460 PNG frames with transparent padding.
- JavaScript syntax checks pass.
- Crowd remains the proportional 1820×403 sharp banner.
- Locked v32 checksum remains unchanged.
